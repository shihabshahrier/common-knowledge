## Directory Tree

```
$CK_HOME/                             ← Git root (e.g. ~/common-knowledge)
├── .git/
├── .gitignore
├── README.md                         ← Auto-generated project index (regenerated by `status`)
│
├── _global/                          ← Cross-project, non-project-specific knowledge
│   ├── agent-config.md               ← AI agent keys, model preferences, environment notes
│   ├── tech-decisions.md             ← Architecture decisions spanning all projects
│   └── integrations.md               ← How projects connect (summary of all connections.md)
│
└── {project-slug}/                   ← One directory per project (kebab-case slug)
    ├── meta.json                     ← Machine-readable project metadata (REQUIRED)
    ├── README.md                     ← Human-readable overview (auto-generated summary)
    ├── codebase-map.md               ← Project structure, entry points, key files
    ├── progress.md                   ← Append-only session log + implementation status
    ├── decisions.md                  ← ADR-style decision log for this project
    ├── connections.md                ← Links to other projects + integration details
    │
    ├── schema/
    │   ├── db.md                     ← Database schema (tables, columns, indexes, relations)
    │   └── db.sql                    ← Raw SQL DDL (optional, if available)
    │
    ├── api/
    │   ├── endpoints.md              ← REST/GraphQL routes, auth, request/response shapes
    │   └── openapi.yaml              ← OpenAPI spec (optional, if available)
    │
    ├── frontend/
    │   └── components.md             ← Key components, state management, routing, build
    │
    ├── infra/
    │   └── overview.md               ← Cloud/infra setup, env vars, deploy process, costs
    │
    └── workers/
        └── overview.md               ← Background jobs, queues, cron jobs, workers
```

## Platform Paths

| OS | Default `CK_HOME` | Shell variable |
|----|-------------------|----------------|
| macOS | `~/common-knowledge` | `$HOME/common-knowledge` |
| Linux | `~/common-knowledge` | `$HOME/common-knowledge` |
| Windows (PowerShell) | `~\common-knowledge` | `$env:USERPROFILE\common-knowledge` |
| Windows (CMD) | `%USERPROFILE%\common-knowledge` | `%USERPROFILE%\common-knowledge` |

**Override:** Set `CK_HOME` environment variable to any absolute path to override the default.

```bash
# macOS / Linux — add to ~/.zshrc or ~/.bashrc
export CK_HOME="/path/to/your/knowledge-store"

# Windows PowerShell — add to $PROFILE
$env:CK_HOME = "C:\path\to\knowledge-store"
```

## meta.json Schema

```json
{
  "name": "Project Display Name",
  "slug": "project-slug",
  "type": "codebase",
  "status": "active",
  "origin_repo": "https://github.com/user/repo",
  "local_path": "/Users/user/Desktop/github/project",
  "tech_stack": ["Go", "React", "PostgreSQL"],
  "related_projects": ["other-slug-1", "other-slug-2"],
  "last_updated": "2026-06-02T03:15:00Z",
  "description": "One-line description of what this project does."
}
```

---

## meta.json Field Reference

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | ✅ | Human-readable display name |
| `slug` | string | ✅ | Kebab-case directory name. Must match `^[a-z0-9]+(-[a-z0-9]+)*$` |
| `type` | string | ✅ | See Valid Types below |
| `status` | string | ✅ | See Valid Statuses below |
| `origin_repo` | string | ⚠️ | Git remote URL. Use `""` if no remote exists |
| `local_path` | string | ⚠️ | Absolute path on this machine. Use `""` if not applicable |
| `tech_stack` | array of strings | ✅ | Technologies used. Empty array `[]` if unknown |
| `related_projects` | array of strings | ✅ | Slugs of connected projects (quick-ref cache — authoritative source is `connections.md`). Auto-updated by `/ck link`. Empty `[]` if none |
| `last_updated` | string | ✅ | ISO 8601 UTC datetime. Update on every write. |
| `description` | string | ✅ | One sentence. What is this project? |

### Input/Output Examples

**Input (save letx):**
```json
{
  "name": "LetX",
  "slug": "letx",
  "type": "codebase",
  "status": "active",
  "origin_repo": "https://github.com/shihabshahrier/letX",
  "local_path": "/Users/shahriar/Desktop/github/letX",
  "tech_stack": ["Next.js", "Node.js", "PostgreSQL", "Redis"],
  "related_projects": ["context-heavy"],
  "last_updated": "2026-06-02T03:15:00Z",
  "description": "Marketing automation and indexing platform."
}
```

**Output (load letx):**
```
Project: LetX (letx)
Type: codebase | Status: active
Repo: https://github.com/shihabshahrier/letX
Local: /Users/shahriar/Desktop/github/letX
Stack: Next.js, Node.js, PostgreSQL, Redis
Related: context-heavy
Updated: 2026-06-02
Description: Marketing automation and indexing platform.
```

## Valid Types and Statuses

### Project Types

| Type | When to use |
|------|------------|
| `codebase` | A software project / app / service with source code |
| `library` | A reusable package, SDK, or shared dependency |
| `service` | A deployed micro/macro-service (API, worker, queue) |
| `infra` | Infrastructure-only: Terraform, k8s, cloud configs |
| `research` | Research notes, experiments, analysis work |
| `personal` | Personal projects, notes, tasks, life tracking |
| `client` | Client/freelance work |
| `other` | Catch-all for anything else |

### Project Statuses

| Status | Meaning |
|--------|---------|
| `active` | Currently being worked on |
| `planning` | In design/spec phase, no code yet |
| `paused` | On hold, may resume |
| `archived` | Completed or abandoned, kept for reference |
| `production` | Deployed and live, in maintenance mode |

## Directory Purpose Reference

| Directory/File | Read by | Written by | Notes |
|----------------|---------|------------|-------|
| `meta.json` | Agents (machine) | `/ck save`, `/ck init` | Always valid JSON. Never nested. |
| `README.md` | Humans | `/ck status` | Auto-generated index. Don't hand-edit. |
| `codebase-map.md` | Agents | `/ck map` | Architecture + structure. Hand-edit OK. |
| `progress.md` | Agents | `/ck progress`, `/ck save` | Append-only. Never truncate. |
| `decisions.md` | Agents, Humans | `/ck save` | ADR style. Append only. |
| `connections.md` | Agents | `/ck link` | Edge-compatible format for Context-Heavy. Append only. |
| `schema/db.md` | Agents | `/ck schema` | DB schema documentation. |
| `schema/db.sql` | Agents | `/ck schema` | Raw DDL. Optional. |
| `api/endpoints.md` | Agents | `/ck schema` | API documentation. |
| `api/openapi.yaml` | Tools/Agents | `/ck schema` | Optional OpenAPI spec. |
| `frontend/components.md` | Agents | `/ck save --section frontend` | Frontend architecture. |
| `infra/overview.md` | Agents | `/ck save --section infra` | Cloud infra, env vars, costs. |
| `workers/overview.md` | Agents | `/ck save --section workers` | Background jobs and queues. |
| `_global/integrations.md` | Agents | `/ck link` | Cross-project integration map. |
| `_global/tech-decisions.md` | Agents, Humans | Manual | Architecture decisions spanning all projects. |
| `_global/agent-config.md` | Agents | Manual | AI agent keys, model preferences. |

## Init Checklist

When running Phase 1 (init), create these files in this order:

1. `$CK_HOME/.gitignore`
2. `$CK_HOME/README.md`
3. `$CK_HOME/_global/agent-config.md`
4. `$CK_HOME/_global/tech-decisions.md`
5. `$CK_HOME/_global/integrations.md`
6. `git init` → `git add -A` → `git commit`

Do NOT create project directories during init — only on first `save` or `map` for that project.
